# Готовлю как умею

Рецепты, которые получились и не очень, меню на неделю и список покупок — вместе с друзьями.

- `index.html` — сам сайт (дизайн и логика).
- `backend.js` — вход, профили, база рецептов и фото через Supabase.

Сайт публикуется через GitHub Pages. Данные (аккаунты, рецепты, фото) хранятся в Supabase и защищены правилами доступа: читать могут все вошедшие, менять — только автор.
